# Contributor instructions

- Part of the NIRUX desktop. Follow the suite's minimal, keyboard-first X11
  style and use the shared theme/catalogue backend.
- Never move a published tag or replace an immutable release asset. Publish a
  new version for corrections.
- Keep host identities, credentials and private planning material out of source,
  fixtures, commits, screenshots and release notes.
- Test on real authorized hardware; container/VM/virtual-display output is not
  acceptance.
- Imported themes are data. Never execute scripts, hooks or commands from them.
- Report actual evidence and limitations; a running window or thumbnail is not
  proof that Apply changed the desktop.
